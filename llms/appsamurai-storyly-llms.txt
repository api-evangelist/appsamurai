## API Reference
- [List apps](https://docs.storyly.io/reference/listapps.md): List all apps for the authenticated account.
- [List instances](https://docs.storyly.io/reference/listinstances.md): List instances for an app.
- [Get story groups](https://docs.storyly.io/reference/getstorygroups.md): Get story groups by instance or specific story group ID.
- [Create story group](https://docs.storyly.io/reference/createstorygroup.md): Create a new story group.
- [Delete story group](https://docs.storyly.io/reference/deletestorygroup.md): Delete a story group by ID.
- [Update story group](https://docs.storyly.io/reference/updatestorygroup.md): Update an existing story group.
- [Get story group stats](https://docs.storyly.io/reference/getstorygroupstats.md): Get statistics for story groups.
- [Get stories](https://docs.storyly.io/reference/getstories.md): Get stories in a story group.
- [Create story](https://docs.storyly.io/reference/createstory.md): Create a new story.
- [Delete story](https://docs.storyly.io/reference/deletestory.md): Delete a story by ID.
- [Update story](https://docs.storyly.io/reference/updatestory.md): Update an existing story.
- [Get story stats](https://docs.storyly.io/reference/getstorystats.md): Get statistics for stories.
- [List audiences](https://docs.storyly.io/reference/listaudiences.md): List all audiences for the authenticated account.
- [Create audience](https://docs.storyly.io/reference/createaudience.md): Create a new audience.
- [Update audience](https://docs.storyly.io/reference/updateaudience.md): Update an existing audience.
- [List segments](https://docs.storyly.io/reference/listsegments.md): List all segments for the authenticated account.
- [Create segment](https://docs.storyly.io/reference/createsegment.md): Create a new segment.
- [Delete segment](https://docs.storyly.io/reference/deletesegment.md): Delete a segment by label.
